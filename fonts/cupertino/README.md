# Cupertino Icons

Emplacement prévu pour un pack Cupertino Icons distribué conformément à sa licence.

- Famille de registre : `cupertino`
- Nom CSS : inscrire la valeur exacte dans le manifeste.
- Formats : WOFF2/TTF selon les environnements ciblés.
- Mapping : nom symbolique → codepoint exact.

La famille Cupertino ne doit pas être simulée par un glyphe de remplacement en production. Si la police manque, afficher un fallback accessible.

# Berkios Icons Font

Emplacement réservé aux glyphes propriétaires créés par Berkios.

Cette famille peut accueillir les pictogrammes de marque, les icônes propres aux outils Berkios et les glyphes non couverts par les familles génériques.

Chaque nouveau glyphe doit être documenté avec :
- identifiant stable ;
- nom et codepoint Unicode privé, si une police privée est créée ;
- catégorie ;
- aperçu SVG ;
- description accessible ;
- version de la police et licence.

# Material Icons

Emplacement prévu pour un pack Material Icons distribué conformément à sa licence.

- Famille de registre : `material`
- Nom CSS conseillé : défini par le fichier de police retenu et inscrit au manifeste.
- Formats conseillés : WOFF2 pour le Web, TTF si nécessaire pour certains moteurs natifs.
- Mapping : nom symbolique → codepoint exact de la police retenue.

Ne pas copier un code numérique provenant d'un catalogue Flet ou d'un enum de framework en supposant qu'il s'agit d'un codepoint de police. Vérifier la table de caractères de la police elle-même.

Ajouter la licence et la provenance avant d'ajouter les binaires.

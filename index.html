Utilisation rapide

Exemple CSS avec une police fournie par ce dépôt (le nom de famille et le fichier exacts seront ceux du manifeste publié).

@font-face {
  font-family: "BerkiosMaterialSymbols";
  src: url("./fonts/material/MaterialSymbolsOutlined.ttf") format("truetype");
  font-style: normal;
  font-weight: 100 700;\n  font-feature-settings: "liga";
  font-display: swap;
}

.icon {
  font-family: "BerkiosMaterialSymbols";
  font-style: normal;
  line-height: 1;
}
Important : le dépôt centralise le format, les identifiants et les consignes d'intégration. Chaque police, pack ou icône importé doit être accompagné de sa licence et de sa provenance. Ne pas supposer qu'une police est installée simplement parce que son catalogue est documenté.

# Catégorie — Design et composants

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:palette` | Palette | Couleurs et thème |
| `berkios:brush` | Pinceau | Dessin ou style |
| `berkios:widgets` | Composants | Bibliothèque de composants |
| `berkios:text` | Texte | Élément de texte |
| `berkios:button` | Bouton | Élément bouton |
| `berkios:visibility` | Afficher | Afficher un contenu |
| `berkios:visibility-off` | Masquer | Masquer un contenu |
| `berkios:star` | Favori | Marquer comme favori |
| `berkios:favorite` | Cœur | Préférence ou appréciation |
| `berkios:bookmark` | Signet | Enregistrer un repère |

Les icônes de contrôle doivent reprendre la couleur et la taille du thème hôte sans modifier leur dessin. Prévoir des variantes de contraste suffisantes.

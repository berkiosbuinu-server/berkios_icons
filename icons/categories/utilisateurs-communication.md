# Catégorie — Utilisateurs et communication

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:person` | Utilisateur | Profil individuel |
| `berkios:group` | Équipe | Groupe ou équipe |
| `berkios:people` | Utilisateurs | Liste d'utilisateurs |
| `berkios:mail` | E-mail | Courrier électronique |
| `berkios:phone` | Téléphone | Appel |
| `berkios:chat` | Discussion | Conversation |
| `berkios:send` | Envoyer | Envoyer un message |
| `berkios:notifications` | Notifications | Centre de notifications |

Les avatars, messages, appels et alertes sont des concepts différents. Ajouter un texte accessible pour différencier une action d'appel d'une action d'envoi de message.

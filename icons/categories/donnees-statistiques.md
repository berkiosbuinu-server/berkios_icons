# Catégorie — Données et statistiques

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:dashboard` | Tableau de bord | Vue synthétique |
| `berkios:analytics` | Analytique | Analyse de données |
| `berkios:chart` | Graphique | Visualisation |
| `berkios:table` | Tableau | Données tabulaires |
| `berkios:database` | Base de données | Stockage structuré |
| `berkios:cloud` | Cloud | Service distant |
| `berkios:trending-up` | Hausse | Tendance positive |
| `berkios:trending-down` | Baisse | Tendance négative |
| `berkios:percent` | Pourcentage | Taux ou ratio |

Une hausse n'est pas toujours une bonne nouvelle et une baisse n'est pas toujours négative : contextualiser les indicateurs avec un libellé et une valeur.

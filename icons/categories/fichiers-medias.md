# Catégorie — Fichiers et médias

Cette catégorie regroupe les fichiers, documents, médias et commandes de lecture.

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:folder` | Dossier | Répertoire |
| `berkios:file` | Fichier | Fichier générique |
| `berkios:document` | Document | Document bureautique |
| `berkios:image` | Image | Média image |
| `berkios:camera` | Caméra | Capture d'image |
| `berkios:play` | Lecture | Démarrer une lecture |
| `berkios:pause` | Pause | Suspendre |
| `berkios:stop` | Arrêter | Terminer |
| `berkios:print` | Imprimer | Imprimer un document |

Les contrôles multimédias doivent distinguer lecture, pause et arrêt. Les icônes de fichiers ne doivent pas remplacer le nom ou le type MIME dans les vues accessibles.

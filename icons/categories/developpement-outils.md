# Catégorie — Développement et outils

Cette catégorie reprend les icônes de développement du catalogue interne.

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:api` | API | Interface de programmation |
| `berkios:code` | Code | Source ou édition de code |
| `berkios:link` | Lien | Référence ou lien externe |
| `berkios:build` | Outils | Construction et outils |

Les icônes de développement ne doivent pas être confondues avec les commandes d'édition génériques.

# Catégorie — Interface et navigation

Icônes de structure et d'orientation dans une application.

## Icônes du catalogue Berkios actuel

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:home` | Accueil | Retour à l'écran d'accueil |
| `berkios:menu` | Menu | Ouvrir une navigation |
| `berkios:arrow-back` | Retour | Revenir à l'étape précédente |
| `berkios:arrow-forward` | Suivant | Avancer dans un parcours |
| `berkios:chevron-down` | Déplier | Développer une section |
| `berkios:close` | Fermer | Fermer une fenêtre ou un panneau |
| `berkios:more` | Plus | Actions supplémentaires |

## Bonnes pratiques

- Une icône de navigation doit avoir une signification stable.
- Les commandes sans libellé visible doivent recevoir un nom accessible.
- Ne pas utiliser une icône de fermeture pour une action de suppression définitive.
- Garder des tailles et alignements homogènes dans une même barre.

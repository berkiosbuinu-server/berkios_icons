# Catégorie — Commerce et métiers

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:cart` | Panier | Panier d'achat |
| `berkios:store` | Boutique | Point de vente |
| `berkios:package` | Colis | Colis ou paquet |
| `berkios:inventory` | Stock | Inventaire |
| `berkios:receipt` | Facture | Reçu ou facture |
| `berkios:payment` | Paiement | Paiement |
| `berkios:wallet` | Portefeuille | Solde ou portefeuille |
| `berkios:truck` | Livraison | Transport ou livraison |
| `berkios:excel` | Excel | Fichier ou fonctionnalité Excel |

Les icônes métier doivent être cohérentes dans toutes les applications Berkios (pharmacie, commerce, comptabilité, éducation). La catégorie n'est pas un remplacement du contexte métier.

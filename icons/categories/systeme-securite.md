# Catégorie — Système et sécurité

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:settings` | Paramètres | Configuration |
| `berkios:help` | Aide | Documentation ou assistance |
| `berkios:info` | Information | Détail informatif |
| `berkios:warning` | Alerte | Avertissement |
| `berkios:error` | Erreur | Échec ou problème |
| `berkios:key` | Clé | Clé ou identifiant d'accès |
| `berkios:lock` | Verrouiller | Verrouillage |
| `berkios:unlock` | Déverrouiller | Déverrouillage |
| `berkios:wifi` | Wi-Fi | Réseau sans fil |
| `berkios:battery` | Batterie | État d'alimentation |

Ne jamais utiliser la seule icône comme indicateur d'une erreur critique ou d'un état de sécurité. Afficher aussi un texte explicite.

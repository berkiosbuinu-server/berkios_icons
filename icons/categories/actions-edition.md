# Catégorie — Actions et édition

Commandes déclenchées par l'utilisateur pour modifier ou gérer un élément.

| Identifiant | Libellé | Usage |
|---|---|---|
| `berkios:add` | Ajouter | Créer un élément |
| `berkios:remove` | Retirer | Retirer un élément d'une collection |
| `berkios:edit` | Modifier | Passer en mode édition |
| `berkios:delete` | Supprimer | Supprimer avec confirmation si nécessaire |
| `berkios:save` | Enregistrer | Enregistrer des changements |
| `berkios:download` | Télécharger | Récupérer un fichier |
| `berkios:upload` | Importer | Envoyer ou importer un fichier |
| `berkios:refresh` | Actualiser | Recharger les données |
| `berkios:search` | Rechercher | Lancer une recherche |
| `berkios:filter` | Filtrer | Affiner une liste |

Séparer visuellement les actions destructives des actions de validation. Les états désactivés, chargement et succès ne doivent pas être exprimés uniquement par la couleur.

# Catégories d'icônes

Les familles et les catégories sont deux notions distinctes :

- **Famille** : provenance et moteur de rendu (Berkios, Material, Cupertino, SVG, custom).
- **Catégorie** : sens fonctionnel (navigation, actions, fichiers, données, etc.).

Une même famille contient des icônes de plusieurs catégories. Une catégorie peut mélanger plusieurs familles.
